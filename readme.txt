MAPA INTERATIVO NUVRA
====================

Conteúdo do pacote:
- index.html
- assets/logo-nuvra.png

Como publicar no Netlify (sem domínio próprio):
1. Acesse https://app.netlify.com/
2. Crie sua conta gratuita.
3. Clique em "Add new site" > "Deploy manually".
4. Arraste a pasta do projeto ou envie os arquivos deste pacote.
5. O Netlify criará um link gratuito em .netlify.app.
6. Depois, gere o QR Code usando esse link.

Observações:
- A página é mobile-first e otimizada para visualização em celular (9:16).
- Ao clicar em um estado, a página mostra o representante responsável.
- No estado de São Paulo, abre uma seleção por sub-região.
- Os botões de WhatsApp usam a mensagem: "Gostaria de saber mais sobre a Nuvra".

Se você quiser alterar contatos ou áreas atendidas, basta editar o arquivo index.html.
